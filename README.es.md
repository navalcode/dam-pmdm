# Apuntes de colaboración con Git

[English](README.md) · [Decisiones de presentación](DESIGN.md) · [Evidencia de revisión](docs/verification.json)

Apuntes históricos de formación sobre ramas y colaboración en pareja. El snapshot original revisado contiene un único README; sus notas breves se conservan debajo.

## Contenido y alcance

Los títulos originales incluyen introducción a Git, trabajo en equipo con ramas y JIRA. Describen el temario del ejercicio. Ese snapshot no contiene aplicación, configuración de build, ejemplo ejecutable, integración con Jira o suite de pruebas.

Se conserva como material de una etapa inicial de aprendizaje. La revisión actual aclara qué contiene y añade navegación equivalente en español e inglés. Esos títulos no se convierten en afirmaciones de uso profesional o software publicado.

Para ejemplos ejecutables de Android, Flutter e ingeniería, puedes partir de [mi perfil GitHub](https://github.com/navalcode). El [historial del repositorio](https://github.com/navalcode/dam-pmdm/commits/main/) conserva el contexto original.

## Verificación

Se inspeccionaron el árbol de fuentes y las notas originales. Ambos README se comprueban con el render Markdown de GitHub y se revisan sus enlaces relativos. Las pruebas de runtime y capturas de aplicación no corresponden a esta superficie documental. No se añade CI, aplicación, actualización de dependencias o cambio de visibilidad.

GitHub proporciona tipografía, tema, navegación y comportamiento responsive. La revisión usa jerarquía temática breve y enlaces reales, sin imágenes decorativas o una app simulada.
